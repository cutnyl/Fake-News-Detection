# Fake - True News Detection

## Project Description
This project aims to develop a machine-learning model capable of classifying any news article as fake or not. I have used two techniques to determine the best model techniques and used it for classifiying and resulting the prediction.
1. Logistic Regression
2. Naive Bayes

## Usage
Follow these steps to run the program on your local device. 

1.  **Clone Repository**: Clone this repository on your local device. 
2.  **Open in Cursor**: Open the project folder using the **Cursor** editor or your preferred IDE.
3.  **Environment Preparation**: Make sure you have installed the necessary dependencies (such as Python or Node.js, depending on the technology used).
4.  **Running the Application**:
    * If using a local web server, run the command: `[insert running command here, e.g., npm start or python app.py]`
    * Or open the `index.html` file directly through the *Live Server* feature.
5.  **Application Access**: Open a browser and navigate to the appropriate `localhost` address to start using the application.

## Inference
you can enter the test text and the model will immediately show the prediction results.

We evaluated each classifier's performance using metrics such as accuracy, precision, recall, and F1 score. The results are documented in the project files.
